# Knock desktop App

Download pages for the **Knock** desktop app (Windows and macOS). This repository only holds the
installers; Knock itself is developed in a private repository.

## Download

| System | File |
|---|---|
| macOS (Apple Silicon and Intel) | [Knock.dmg](https://github.com/HASEL-UZH/Knock-Releases/releases/latest/download/Knock.dmg) |
| Windows 10 / 11 | [Knock-Setup.exe](https://github.com/HASEL-UZH/Knock-Releases/releases/latest/download/Knock-Setup.exe) |

All versions: [Releases](https://github.com/HASEL-UZH/Knock-Releases/releases).

## Install

**macOS:** open `Knock.dmg` and drag Knock into *Applications*. The app is signed and notarized by the
University of Zurich, so macOS opens it without a warning.

**Windows:** run `Knock-Setup.exe`. The app is not code-signed yet, so Windows SmartScreen may say
"Windows protected your PC": click **More info**, then **Run anyway**.

## Good to know

- Knock starts when you log in and keeps running in the background (tray icon on Windows, menu bar
  on macOS), so colleagues can see your status and knock on you. Closing the window only hides it;
  use *Quit Knock* in the tray menu to really quit.
- The app updates itself: it checks this page for a newer version and asks you to restart.
- The app opens the Knock web app, so you log in with the same account as in the browser.
